# Fitness Benchmark

Benchmarks RNA foundation models on fitness prediction using deep mutational scanning (DMS) assays. Models are scored on how well their predictions correlate with experimentally measured mutational effects.

## Directory Structure

```
fitness/
├── baselines/               # Scoring scripts for each model
│   ├── Evo/
│   ├── EVmutation/
│   ├── GenSLM/
│   ├── Nucleotide_Transformer/
│   ├── RiNALMo/
│   ├── RNA_FM/
│   └── RNAERNIE/
├── utils/                   # Helpers (table conversion, CV splits)
├── reference_sheet_final.csv    # Assay metadata (RNA type, sequence, etc.)
├── merge_scoring_files.py       # Merge assays with model predictions
└── performance_fitness.py       # Evaluate models and produce result tables
```

### Data directories (not in repo)

The following directories are gitignored. Download them from
<https://marks.hms.harvard.edu/rnagym/fitness_prediction>:

| Directory | Archive to download |
|-----------|---------------------|
| `assays/` | `fitness_processed_assays.zip` — 70 processed DMS assay CSVs |
| `model_predictions/` | `model_predictions.zip` — pre-computed model scores per assay |
| `merged/` | Generated by `merge_scoring_files.py` (or `fitness_results.zip` for published results) |
| `results_*/` | Generated by `performance_fitness.py` |

## Metrics

- **Spearman** — signed Spearman correlation between predicted and experimental scores. A negative value means the model ranks variants the wrong way round, which the metric reports rather than hides
- **AUC** — AUROC using median-threshold binarisation (max of AUC and 1−AUC)
- **MCC** — absolute Matthews correlation coefficient (median-threshold binarisation)

## Usage

### 1. Download data

```bash
# Download and unzip into fitness/
wget https://marks.hms.harvard.edu/rnagym/fitness_prediction/fitness_processed_assays.zip
wget https://marks.hms.harvard.edu/rnagym/fitness_prediction/model_predictions.zip
unzip fitness_processed_assays.zip -d fitness/assays
unzip model_predictions.zip -d fitness/model_predictions
```

### 2. Merge assay data with model predictions

```bash
python fitness/merge_scoring_files.py \
    --processed_folder fitness/assays \
    --model_predictions_folder fitness/model_predictions \
    --output_folder fitness/merged
```

### 3. Evaluate model performance

```bash
python fitness/performance_fitness.py \
    --reference_file fitness/reference_sheet_final.csv \
    --combined_dir fitness/merged \
    --performance_dir fitness/results
```

Key flags:

| Flag | Description |
|------|-------------|
| `--type {all,non-coding,coding}` | Filter assays by RNA type (default: all) |
| `--msa_only` | Restrict to datapoints where EVmutation has scores |
| `--calculate_se` | Compute bootstrap standard errors (slow) |
