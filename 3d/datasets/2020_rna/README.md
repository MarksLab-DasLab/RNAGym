# Data sourced from 2020 RNA

These 70 structures and MSAs were collected from the 2020 RNA paper
titled "Evaluating DCA-based method performances for RNA contact
prediction by a well-curated data set".

## Citation

Pucci F, Zerihun MB, Peter EK, Schug A. Evaluating DCA-based method
performances for RNA contact prediction by a well-curated data set. RNA.
2020 Jul;26(7):794-802. doi: 10.1261/rna.073809.119. Epub 2020 Apr 10.
PMID: 32276988; PMCID: PMC7297115.
