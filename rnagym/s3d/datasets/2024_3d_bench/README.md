# 10.1101/2024.11.27.625779

Datasets from 10.1101/2024.11.27.625779 titled "A Comparative Review of
Deep Learning Methods for RNA Tertiary Structure Prediction".  Datasets
were stripped for only the corresponding PDB IDs in each dataset.
Dataset 4 is a subset of Data 3, which is a set of RNA PDBs from after
April 2022.  Dataset 1 and Dataset 2 are ignored because they
represented RNA Puzzles and CASP15, respectively.

## Citation

Martinović, I., Vlašić, T., Li, Y., Hooi, B., Zhang, Y., & Šikić, M.
(2024). A Comparative Review of Deep Learning Methods for RNA Tertiary
Structure Prediction. bioRxiv. https://doi.org/10.1101/2024.11.27.625779
