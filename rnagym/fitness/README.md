# Fitness benchmark

The fitness benchmark evaluates RNA foundation models against experimentally
measured effects from 70 deep mutational scanning assays. The published ncRNA
leaderboard reports signed Spearman correlation, averaged equally across the
ribozyme, tRNA and aptamer categories.

## Directory structure

```

├── baselines/                   # Model scoring scripts
│   ├── AIDO_RNA/
│   ├── EVmutation/

│   ├── Nucleotide_Transformer/
│   ├── Orthrus/
│   ├── RiNALMo/
│   ├── RNAERNIE/
│   ├── RNAGenesis/
│   ├── RNA_FM/
│   └── masked_lm/               # Shared masked-marginal engine
├── pixi.toml                    # Workflow, test and model environments
├── tasks/
│   ├── analyze_fill_strategies.py   # Compare the four fill conventions
│   ├── check_published.py            # Reproduce released model scores
│   ├── merge_scoring_files.py       # Merge assays with predictions
│   ├── model_registry.py            # Prediction folders and score columns
│   └── performance_fitness.py       # Produce benchmark tables
└── utils/                       # Table conversion and CV split helpers
```

### Data layout

Fitness data lives under `data/fitness`. The downloaded and generated
directories are gitignored. The reference sheet is versioned with the repo.
Set `RNAGYM_DATA_DIR` to the parent data directory only when using data outside
the repository checkout.

| Directory | Contents |
|-----------|----------|
| `data/fitness/assays/` | `fitness_processed_assays.zip`: 70 processed DMS assay CSVs |
| `data/fitness/msa/by_assay/` | Riboseek A3M alignments and matching query FASTA files |
| `data/fitness/model_predictions/` | `model_predictions.zip`: precomputed model scores per assay |
| `data/fitness/merged/` | Generated by `merge_scoring_files.py` |
| `data/fitness/reference_sheet_final.csv` | Assay metadata and wild-type constructs |
| `data/fitness/reports/` | Generated benchmark metric tables |

## Metrics

- **Spearman**: signed correlation between predicted and experimental scores
- **AUC**: AUROC of continuous model scores against assay labels split at their median
- **MCC**: signed Matthews correlation after both score vectors are split at their medians

Values below 0 for Spearman or MCC, and below 0.5 for AUC, mean that the model
ranks variants in the wrong direction.

## Usage

### 1. Create the environment

```bash
cd rnagym/fitness
pixi install
```

The default environment runs merging, analysis and the checkpoint-free test
suite. Model inference runs in isolated environments selected with `-e`.

### 2. Download data

From the repository root, download the archives published at the
[fitness data site][0]:

```bash
cd data/fitness
wget https://marks.hms.harvard.edu/rnagym/fitness_prediction/fitness_processed_assays.zip
wget https://marks.hms.harvard.edu/rnagym/fitness_prediction/model_predictions.zip
unzip fitness_processed_assays.zip -d assays
unzip model_predictions.zip -d model_predictions
```

### 3. Merge assay data with model predictions

```bash
cd rnagym/fitness
pixi run merge
```

The merge defaults to the 31 ncRNA leaderboard assays. Pass `--type coding`,
`--type non-coding` or `--type all` to select another assay group. As of
`v0.2`, not all models are tested on coding or splice variants.

### 4. Evaluate model performance

```bash
cd rnagym/fitness
pixi run leaderboard
```

The command prints metrics and writes the detailed tables under
`data/fitness/reports`. Pass `--performance_dir` to use another directory.

Key flags:

| Flag | Description |
|------|-------------|
| `--type {all,ncRNA,non-coding,coding}` | Select an assay group. The default is the 31-assay ncRNA leaderboard. `non-coding` also includes mRNA-splicing |
| `--msa_only` | Restrict to datapoints where EVmutation has scores |
| `--models MODEL ...` | Evaluate selected merged model columns instead of the defaults |

### 5. Run model inference

```bash
cd rnagym/fitness
SLURM_ARRAY_TASK_ID=12 pixi run -e ntv3 predict
```

`SLURM_ARRAY_TASK_ID` defaults to 0. Checkpoints are fetched when needed.
GenSLM is the exception because its checkpoint is distributed through
authenticated Globus; its `weights` task prints the fixed destination.
Gated Hugging Face checkpoints require prior access and an authenticated login.
EVmutation processes every assay with a Riboseek MSA in one run.

### 6. Check published predictions

```bash
pixi run -e ntv3 check-published
pixi run check-published
```

The first checks one model family. The second checks every leaderboard
checkpoint on one complete assay, allowing only small numerical drift.

## Quality checks

Run these commands from `rnagym/fitness/`:

```bash
pixi run test
pixi run coverage
pixi run lint
pixi run fmt
```
